Расширенный курс по платформе МПК-Пересвет

Продолжение базового курса. Каждый урок подробно разбирает одну тему, которую базовый курс только наметил. Уроки начинаются с модели насосной станции, на которой закончился базовый курс, поэтому их можно проходить в любом порядке.

Подготовка

С чего начинать

  • Пройден базовый курс. На стенде собрана модель насосной станции: теги и объекты, метод «Расчёт мощности», тревога «Высокий уровень», расписание, камера и экран «Насосная станция». Каждый урок расширенного курса начинается с этой модели.
  • Знания из подготовки к базовому курсу — формат JSON, основы JSONata и Python — нужны в каждом уроке.
  • Для отдельных тем понадобится больше: администрирование Docker и Linux — для устройства платформы, SQL — для интеграционных хранилищ, HTML и JavaScript — для видео на своей странице. В начале каждого урока сказано, что именно нужно.
